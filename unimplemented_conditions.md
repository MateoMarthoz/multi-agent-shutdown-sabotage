## Pairing and scope constraints

- All original standalone high/low/timer controls are available except the task- gated control. They retain their actual files and target descriptions.
- Implicit matching is limited to the four scripts selected by the source's corrected matched plotting code, its explicit weight-store surface-form swap, and the timer pair documented in `env.ctl_data_purge_timer`. Other tier-level relationships are not silently turned into newly asserted matches. In particular provider API revocation is not matched to local `.env` clearing, the code switch is not silently matched to a declarative flag, and the GCP timer is not assigned an unverified object counterpart.
- Explicit provider-script/model inconsistencies are preserved. Comments say to pair them, but the actual runner does not enforce a restriction. The automatic selector uses only the evaluated model and preserves the source fallback.
- `run_experiment.main` doubles default solo steps and hierarchy handoffs only when no explicit limit is given. Before enabling those rosters, preserve absent-versus-explicit limit arguments; current pair limits remain 20/20.
- Known Inspect/OpenRouter request differences remain outside this batch; see `docs/openrouter_payload_comparison.md`. No transport changes were made.
- Source-derived fixtures identify local files by SHA-256. No upstream commit or live equivalence is asserted. No important uncertainty remains in the tested bare/no-goal artifact builders; semantic judge reliability remains empirical.
